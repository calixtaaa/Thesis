Raspberry Pi 5 GPIO and MCP23017 Connections

IMPORTANT:
- Use a common GND between Raspberry Pi and all external 12V driver supplies.
- Do NOT drive motors/solenoids directly from Pi GPIO.
- ULN2003 controls the motor coils; MCP23017 provides extra control pins for ULN2003 IN1..IN4.

========================================
1) MFRC522 RFID Reader (single shared module)
========================================
Shared SPI lines:
- SCK  -> GPIO11 (Physical pin 23)
- MOSI -> GPIO10 (Physical pin 19)
- MISO -> GPIO9  (Physical pin 21)
- VCC  -> 3.3V
- GND  -> GND

Shared reader control:
- SDA/SS -> GPIO8  (Physical pin 24, CE0)
- RST    -> GPIO5  (Physical pin 29)

RFID flow usage:
- Payment tap
- Card reload tap
- Restock door unlock authorization tap
- Troubleshoot door unlock authorization tap (admin role only)

========================================
2) Stepper Expansion (28BYJ-48 + ULN2003 + MCP23017-E/SP)
========================================
Power Supply:
- 12V / 12.5A Switched-Mode Power Supply (SMPS)
- Output: +12V (nominal 12V, typical range 11.5–12.5V under load)
- Capacity: 150W continuous (12V × 12.5A)
- Purpose: Powers all ULN2003 stepper driver boards and solenoid relay coils
- Protection: Tie PSU GND to Pi GND for common reference; do NOT float the ground

Per ULN2003 board (12V motor variant):
- Motor connector -> ULN2003 motor socket
- ULN2003 V+ / DC+ -> +12V from SMPS
- ULN2003 GND / DC- -> SMPS GND
- Pi GND -> same SMPS GND (common ground)
- MCP23017 GPIO -> ULN2003 IN1, IN2, IN3, IN4

MCP23017 bus wiring:
- Pi GPIO2  (Physical pin 3)  -> SDA
- Pi GPIO3  (Physical pin 5)  -> SCL
- 3.3V -> VDD
- GND  -> VSS
- RESET -> 3.3V through a pull-up resistor (recommended: 10k ohm; acceptable range: 4.7k to 10k)
- A0/A1/A2 set per chip address

Configured expander addresses in software:
- MCP #1: 0x20
- MCP #2: 0x21
- MCP #3: 0x22

Slot to expander pin mapping (main.py default):
- Slot 1:  0x20 GP0..GP3
- Slot 2:  0x20 GP4..GP7
- Slot 3:  0x20 GP8..GP11
- Slot 4:  0x20 GP12..GP15
- Slot 5:  0x21 GP0..GP3
- Slot 6:  0x21 GP4..GP7
- Slot 7:  0x21 GP8..GP11
- Slot 8:  0x21 GP12..GP15
- Slot 9:  0x22 GP0..GP3
- Slot 10: 0x22 GP4..GP7

Notes:
- Runtime selects MCP mode by default on Raspberry Pi.
- To force old direct GPIO stepper mode, set STEPPER_BACKEND=native_gpio before launching.
- MCP logical pin map in tools/tests:
	- GPA0..GPA7 = pins 0..7
	- GPB0..GPB7 = pins 8..15
	- GPB0 specifically equals logical pin 8

========================================
3) Solenoid Locks (12V Solenoid Model 102)
========================================
Songle dual-channel 5V relay module (JD-VCC + VCC type):
- Keep JD-VCC <-> VCC jumper installed for simple single-supply mode.
- Relay VCC/JD-VCC -> Pi 5V (Physical pin 2 or 4)
- Relay GND -> Pi GND (Physical pin 6)
- IN1 -> GPIO16 (Physical pin 36)  [restock lock]
- IN2 -> GPIO20 (Physical pin 38)  [troubleshoot lock]

About the two GND pins and two VCC pins:
- With jumper installed, the two power domains are tied; one GND connection is enough.
- If convenient, both GND pins can be tied to the same ground rail.
- Remove jumper only for split/isolated supply experiments.

Relay contact wiring for each 12V solenoid lock:
- External PSU +12V -> COM (relay channel)
- NO (relay channel) -> Solenoid +
- Solenoid - -> External PSU GND
- Tie external PSU GND to Pi GND (common reference)

Protection and behavior notes:
- Add flyback diode across each solenoid coil:
	stripe/cathode -> solenoid +, anode -> solenoid -
- Most Songle relay modules are active-low:
	IN=LOW energizes relay, IN=HIGH releases relay.
- Keep unlock pulse short (for example 1-3 seconds); many lock solenoids are not meant for long continuous hold.

4) Cash Input (coin-only)
========================================
Coin acceptor pulse output:
- Pulse OUT -> GPIO19 (Physical pin 35)

Coin acceptor relay control (NEW):
- Relay IN -> GPIO6 (Physical pin 31)
- Logic: Active-high (HIGH=enabled, LOW=disabled) — relay module active-high logic
- Activation: When user selects "Pay with Coins" payment method
- Deactivation: Automatically when required amount is reached, after payment completes, or when user cancels/goes back
- Purpose: Enables coin acceptor only during active payment collection
- Protection: Starts in disabled state (LOW) on system boot

Removed hardware in current build:
- Bill acceptor (not used)
- Coin change hopper(s) and hopper pulse feedback lines (not used)

6) I2C Bus Troubleshooting (MCP23017 errno 121)
========================================
Symptom: `i2cdetect -y 1` shows MCP addresses (0x20, 0x21, 0x22), but stepper_mcp.py or main.py fails with errno 121 (Remote I/O error).

Common causes and fixes:

1) SDA/SCL wires swapped or loose:
   - Verify Pi GPIO2 (Physical pin 3) -> MCP SDA
   - Verify Pi GPIO3 (Physical pin 5) -> MCP SCL
   - Check all connections are secure; no cold solder joints
   - If using breadboard, verify tight wire insertion

2) Missing or broken common ground:
   - Tie Pi GND -> SMPS GND -> all MCP boards VSS pin
   - Use multiple GND wires if board layout is spread out
   - Check continuity: Pi GND to SMPS GND should read 0 ohms
   - Check continuity: Pi GND to each MCP VSS should read 0 ohms

3) MCP VDD power failure:
   - MCP23017 requires 3.3V on VDD pin
   - Measure voltage at MCP VDD with multimeter; should read 3.3V ±5%
   - If low, check 3.3V line on Pi and verify no solder bridges

4) Missing RESET pull-up resistor:
   - MCP23017 RESET pin must be pulled up to 3.3V via 4.7k–10k ohm resistor
   - If floating, the chip may not initialize properly
   - Add resistor: 3.3V -> [4.7k–10k ohm] -> MCP RESET pin

5) Address straps (A0, A1, A2) misconfigured:
   - MCP #1 (0x20): A0=GND, A1=GND, A2=GND
   - MCP #2 (0x21): A0=3.3V, A1=GND, A2=GND
   - MCP #3 (0x22): A0=GND, A1=3.3V, A2=GND
   - Use multimeter to check voltage at each A pin

6) Intermittent connection (marginal wiring):
   - `i2cdetect` may succeed (simpler probe) while register read fails (errno 121)
   - If addresses disappear/reappear, suspect loose wire or cold joint
   - Power cycle Pi or unplug/re-insert MCP boards and retry
